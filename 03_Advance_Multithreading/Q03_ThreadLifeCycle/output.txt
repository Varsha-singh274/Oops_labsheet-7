$ javac Q03_ThreadLifeCycle.java
$ java Q03_ThreadLifeCycle

1. After creating the thread        : NEW
2. Immediately after start()        : RUNNABLE
   [inside thread] state while running  : RUNNABLE   (RUNNING = RUNNABLE + has CPU)
3. Worker waiting for main's lock    : BLOCKED
   [inside thread] got the lock, now sleeping 500 ms...
4. Worker inside Thread.sleep()      : TIMED_WAITING
5. After run() has completed         : TERMINATED
6. Thread that called lock.wait()    : WAITING
7. After notify() and completion     : TERMINATED
